# 🚦 Urban Traffic & Accident Pattern Analytics in India

## 📊 Project Overview
An end-to-end Data Analytics project analyzing urban accident patterns, high-risk spatial hotspots, temporal/environmental risk factors, and causal mechanisms in India.

---

## 🛠️ Tech Stack & Workflow
- **Microsoft Excel:** Initial Data Inspection & Data Cleaning.
- **SQL:** Data Transformation, Aggregations & Analytical Queries.
- **Power BI Desktop:** Multi-page Interactive Dashboard with Dynamic Buttons, Custom Visuals & AI Decomposition Tree.

---
